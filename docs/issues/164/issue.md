# Issue #164: 本番環境でリロード時にローカルAPIエンドポイントにアクセスしてしまう問題

## 基本情報

- **Issue番号**: #164
- **タイトル**: 本番環境でリロード時にローカルAPIエンドポイントにアクセスしてしまう問題
- **状態**: OPEN
- **作成日時**: 2025-09-22T06:03:01Z
- **更新日時**: 2025-09-22T06:03:01Z
- **ラベル**: bug, frontend, production, high priority

## 問題の概要

本番のrepo詳細ページでリロードを行うと、フロントエンドがローカルテスト用のAPIエンドポイント（`http://localhost:23000/api/recheck/...`）にアクセスしてしまう問題が発生しています。

## 現在の動作

- **初回アクセス時**: 正常に本番用APIにアクセス
- **リロード時**: ローカルテスト用API（`http://localhost:23000`）にアクセスしてしまう

## 期待される動作

リロード時も初回アクセス時と同様に、本番用APIにアクセスする必要があります。

## 技術的詳細

- フロントエンド: Nuxt.js
- バックエンド: Node.js/Express
- 問題のエンドポイント例: `http://localhost:23000/api/recheck/TeckVeho/drivee-link/status`

## 影響範囲

- 本番環境でのユーザー体験の悪化
- リロード時にAPIエラーが発生する可能性

## 優先度

High - 本番環境での重要な機能に影響

## 関連ファイル

- フロントエンドのAPI設定ファイル
- 環境変数設定
- ルーティング設定

## 調査が必要な項目

1. フロントエンドのAPIベースURL設定の確認
2. 環境変数の設定状況
3. リロード時の初期化処理
4. 本番環境とローカル環境の設定の違い
